Query Shodan for internet-exposed hosts, DNS records, honeypot scores, and exploit metadata.

Use this tool when the user asks about exposed services, open ports, vulnerable hosts, DNS lookups, or exploit/CVE intelligence from Shodan.

Operations:
- host_info: Look up all services on a host IP (requires ip)
- host_search: Search Shodan with query syntax (requires query)
- host_count: Count hosts matching a query without using credits (requires query)
- dns_resolve: Resolve hostnames to IPs (requires hostnames, comma-separated)
- dns_reverse: Reverse DNS for IPs (requires ips, comma-separated)
- honeypot_score: Honeypot probability for an IP (requires ip)
- exploits_search: Search exploit database (requires at least one of query, port, type, osvdb, or cve)
- api_info: Return API plan and usage info
- ports: List ports Shodan crawlers monitor

Requires SHODAN_API_KEY. Access is gated by the shodan permission in config (allow, ask, or deny). When set to ask, the user is prompted before each call.
